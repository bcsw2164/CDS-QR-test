# Project Rules & Guidelines

- Do not capture screenshots, run headless browsers, or perform visual verification automatically.
- Keep explanations short, focus directly on providing updated code, and ALWAYS respond/explain in Korean.
- Always ask before reading large directory trees or searching unnecessary files.
- 코딩만 수정하고, 브라우저 캡처나 자동 테스트는 실행하지 마세요. 모든 설명과 결과 요약은 한국어로 작성합니다.
